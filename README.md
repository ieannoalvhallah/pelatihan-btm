# Sistem Informasi Persediaan - Pelatihan BTM

Aplikasi Sistem Informasi Manajemen Persediaan Barang dan Penjualan berbasis Laravel 13.

## Fitur Utama
- **Autentikasi Pengguna**: Login aman dengan sistem proteksi sesi dan auto-redirect.
- **Dashboard Interaktif**: Statistik KPI persediaan, total barang, kategori, akumulasi stok, dan omzet penjualan.
- **Sidebar Navigasi**: Navigasi responsif di sebelah kiri layar.
- **Manajemen Barang**: Tambah, ubah, hapus, dan cari katalog barang beserta stok dan harga.
- **Manajemen Kategori**: Pengelompokan barang berdasarkan kategori.
- **Transaksi Penjualan Barang**: Pencatatan penjualan dengan nomor transaksi otomatis (`PJL-YYYYMMDD-XXXX`) dan pengurangan stok barang secara real-time.
- **API Endpoints**: Tersedia REST API untuk integrasi frontend/mobile (Barang & Kategori).
